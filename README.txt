Docker + Git + Python Flask Complete Tutorial

CONTENTS
- index.html: detailed step-by-step notes, code samples, tables, quiz and links
- style.css: responsive styling
- script.js: copy buttons, section search, progress checklists and quiz

OPENING THE WEBSITE
1. Extract the ZIP.
2. Keep index.html, style.css and script.js in the same folder.
3. Open index.html in a modern browser.
4. Internet is recommended for Bootstrap, Bootstrap Icons, Google Fonts and the official Mevi logo.

LEARNING ORDER
Docker basics -> commands -> Dockerfile -> volumes/networks -> Compose -> Git/GitHub -> Python environment -> Flask/HTML/CSS/Bootstrap/JavaScript -> Flask with Git -> Flask with Docker -> Compose -> security and CI.

SAFETY
- Never commit secrets or bake credentials into an image.
- Flask debug mode is for local development only.
- Verify version-specific instructions in official documentation.
- Review TLS, authentication, dependencies, backups and monitoring before public deployment.
